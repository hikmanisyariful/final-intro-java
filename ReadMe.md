Follow these steps to run the GetTicketConcert application:

1. Open your terminal (Command Prompt, PowerShell, or Terminal).
2. Navigate to the project directory:
	```
	cd GetTicketConcert
	```
3. Compile the main Java file:
	```
	javac GTCApp.java
	```
	This will generate GTCApp.class and other required class files in the same directory.
4. Run the application:
	```
	java GTCApp
	```
5. Follow the on-screen instructions in the terminal to use the application.
